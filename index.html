What's inside

One repository. Every piece has a job.

No framework of our own to learn. It's a regular Vite + React project, and every file below is code you can read and change.

src/content/proAction.ts

Where your Pro feature goes. It runs on the page only after the user has been confirmed as Pro.

src/config.ts

Name, button label and paywall copy in one place.

src/shared/messages.ts

Typed messages between popup, background and tabs. A wrong payload fails at compile time.

src/background/auth.ts

Supabase sign-up and sign-in. The session lives in chrome.storage; pages only ever see the user's id and email.

src/content/FloatingButton.tsx

In-page UI in a Shadow DOM, so the host site's CSS can't break it. Users can drag it or hide it per site.

supabase/migrations/

The profiles table, row-level security, and a trigger that creates a profile on sign-up.

supabase/functions/

Webhook handlers for Stripe and Lemon Squeezy, with signature checks.

docs/

Setup guides for each payment provider and for publishing to the Chrome Web Store, plus a privacy policy template.

Payments

From "Upgrade" to Pro, without a server of your own.

The checkout carries the user's id. When the payment clears, a Supabase Edge Function flips the flag the extension reads.

01 — Extension

User clicks Upgrade

The background opens your checkout link, tagged with the Supabase user id.

02 — Provider

They pay

Stripe Checkout or Lemon Squeezy handles cards, taxes and receipts.

03 — Edge Function

Webhook is verified

The signature is checked, then profiles.is_pro is set with the service role.

04 — Extension

Pro unlocks

The next CHECK_PRO_STATUS returns true. Refunds and cancellations turn it off again.

Lemon Squeezy works in countries where Stripe isn't available. Switching providers is one line in .env.

FAQ

Who is it for?
Developers who want to sell a Chrome extension — a side project, a micro-SaaS or client work — without spending weeks on auth and billing.
Do I need Stripe?
No. Use Stripe or Lemon Squeezy; it's one setting. Lemon Squeezy also handles sales tax for you.
Do I need a backend?
Only Supabase. Its free tier is enough to start, and the webhooks run as Edge Functions there.
Can I use it for several products?
Yes, including client projects. You just can't resell the boilerplate itself.
Is it a framework?
No. It's a plain Vite + React project. There's nothing to stay locked into.
When does it launch?
Soon. The waitlist hears first and gets the early-bird price.
